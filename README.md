# Till Firmware Do Us Part

A single wedding vow for a robot — one sentence, funny and heartfelt at the same time.

> I vow to spend my last 1% of battery on you, and to keep your name in my memory even after every update wipes the rest.

`main.py` writes the vow to `entry.txt` (119 characters, one sentence).
